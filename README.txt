BADALSTUDIO — ULTRA ANIMATED WEBSITE
===================================

Files:
- index.html
- style.css
- script.js

HOW TO USE ON ANDROID (ACODE)
1. Download and extract BadalStudio_Ultra_Animated.zip.
2. Open the extracted folder in Acode.
3. Open index.html and preview it in a browser.
4. Before publishing, find YOUR_EMAIL_HERE in index.html and replace it with the studio's working contact email.
5. Replace concept projects with real portfolio work or label them clearly as concepts.
6. Test the mobile menu, all section links, mailto button, animations, and responsive layout.
7. Upload all three files to the root of your GitHub Pages repository.

NOTES
- This is a fresh starter package. It does not overwrite your existing BadalStudio files.
- The animated project cards are concept art made with CSS; they are not real client projects.
- The opening animation, background grid, 3D-style CSS cube/rings/sphere, scrolling ticker, scroll reveal, progress line, cursor glow, project hover and mobile menu use CSS/vanilla JS.
- Google Fonts are loaded from the web; a system-font fallback is included.
- The contact link will NOT work until YOUR_EMAIL_HERE is replaced.
- No backend, contact form submission, analytics, or paid service is included.
- Test on your own device before calling it production-ready.
